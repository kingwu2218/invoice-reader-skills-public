# OpenAI MVP 0.3.17 — experimental pre-release

Extract user-selected information from invoices and supporting certificates into
an Excel review workbook through Codex CLI, including ChatGPT sign-in. This
release packages the OpenAI route. Ordinary ChatGPT browser/mobile installation
is not implemented. Gemini, Grok and Anthropic packages remain separate previews
or secondary support and are not included in the release ZIP.

## Install

Download `invoice-reader-openai-0.3.17.zip` and `SHA256SUMS.txt` from the
[GitHub release](https://github.com/kingwu2218/invoice-reader-skills-public/releases/tag/v0.3.17).
Extract the complete `invoice-reader-openai` folder into your personal or project
`.agents/skills/` folder. Follow the [README setup and data-policy guidance](../../README.md).
Invoke explicitly: "Use $invoice-reader-openai to read these documents."

ZIP SHA-256:
`60589005db30b52b39ccccb0d677f6e0f242b30361031eda087c5617ef91a8a4`.
All 35 archive members match the evaluated generated package. The skill keeps
the user's selected model; the recommendation is metadata, not a model override.

## Included

- Flexible finance requirements and per-user `custom.md`, including repeated
  certificate measurements, original units and source evidence.
- PDF routes and a shared capability/rendering runtime, input coverage and
  workbook review flags.
- Three maintained OpenAI prompt parts compiled into one installed `SKILL.md`:
  goals/principles, workflow/custom settings, prohibited behaviours/error handling.
- Reusable evaluators, frozen references and scoped evidence in the repository.
