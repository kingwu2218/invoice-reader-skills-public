## Holdout method and evaluation correction

The private test used four original source pages absent from the earlier model-evaluation/prompt-development runs: three handwritten cheques and one page containing two overlapping documents. It covers dates, amounts, a handwritten project identifier, an overwritten original amount and an occluded invoice number. Single-page copies were checked for pixel-identical rendering against the original pages. Sources, custom settings, raw/workbook answers and package hashes were frozen before the tested model received each case. The owner explicitly approved the four named pages and OpenAI/Codex destination after automatic approval review required more specific authorization.

References are **agent-reviewed provisional**, not owner-adjudicated ground truth. These are source holdouts, not unseen-layout or model-training holdouts. The cheques share a bank form; four pages cannot establish broad handwriting accuracy. All six extractions ran once in the same acknowledged conversation. That exercises per-chat continuity but does not measure independent-run variance. No CLI page-attachment receipts were captured in this staged run; successful output and the model's inspection statements do not establish attention to every image.

An initial workbook score incorrectly failed a custom row because the scorer looked for Document type directly on a sheet that stores Document ID instead. The corrected scorer joins actual document metadata by source filename and unique Document ID, independently of the value being graded. A regression tests same-page documents in reversed row order and rejects ambiguous duplicate IDs. The preliminary score/matrix is preserved locally; unchanged artifacts were rescored. No source values, frozen answers or package prompts were altered to improve the score. A proposed reference v2 was frozen during diagnosis but never executed; the original v1 remains the evaluated reference after the metadata join was fixed.
