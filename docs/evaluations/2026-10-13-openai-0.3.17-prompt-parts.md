# OpenAI 0.3.17 — three-part prompt and fresh regression

Version 0.3.17 separates maintainer authoring into goals/principles, workflow/custom
settings, and prohibited behaviours/error handling. The installed skill remains
one complete entrypoint. The new package is experimental; historical 0.3.16
results and its release archive remain unchanged.

## Change and deterministic verification

The source `SKILL.md` is a metadata/template entry with three ordered includes.
The builder expands each maintained part exactly once and does not ship the
authoring fragments. It rejects missing, duplicate, unreferenced, nested, empty
or unsafe parts, preventing an omitted constraints file from silently producing
a usable-looking package. Existing single-file families retain their output.

The original prose is retained and reorganized. Two explicit statements clarify
that every part applies and custom settings cannot override constraints. Detailed
references, the tool adapter, processor and core 0.3.16 runtime are unchanged.
The changed order/text is treated as a new prompt version, not a byte-identical
refactor. No source-specific answer or example is added.

**326 / 326 tests pass**, including six new composition tests. Generated package,
registry and skill-frontmatter validation pass. The four other generated
packages retain their original hashes. The [maintenance guide](../prompt-maintenance.md)
identifies where each instruction belongs.

The new copied-package installation with a fresh uv cache passes **24 / 24**
checks. PDF probe/preparation share Python 3.14.5, PDFium 5.14.0 and Pillow 12.3.0;
workbook processing uses openpyxl 3.1.5. The rendered public invoice is inspected
and its workbook reopened. This uses a previously reviewed supplied transcription,
not a new model accuracy test. All 35 ZIP members equal the generated package.
See [clean-install evidence](2026-10-13-openai-0.3.17-clean-install.json).
