## Prompt change and host constraint

Only the OpenAI entry and package version change. The entry supplies the optional exact announcement, "I'm using the invoice-reader-openai skill.", and excludes a heading, task recap, setup plan or discretionary closing sentence. It retains the exact policy question/options and receipt of a reply before document work. It preserves higher-priority host instructions and limits any required disclosure to a brief explanation without repeating the question or adding approval requests. Extraction guidance, shared runtime, references and other family packages are unchanged.

All three captured session traces contain the disclosure rule in `session_meta.base_instructions`: a skill-induced pause requires a linked source and explanation. Remaining one-line notes cite the installed skill or its chat-start reference and explain waiting. Removing them through a lower-priority prompt would conflict with that host requirement. No host instructions, user configuration or CLI safety settings were changed to obtain a better score.

The owner's subsequent decision allows that one necessary note. V3 accepts the exact optional announcement, ordered question/options and at most one conservatively recognised explanation linked to the installed entry or chat-start reference. It requires independent host-rule evidence from the matching trace and observed waiting. Extra confirmation, Yes-only conditions, multiple notes, unrelated links and unsupported wording cannot automatically pass. This is a format/interaction check, not complete compliance with every detail of the host's citation instructions.
