## Interpretation and next step

The previous retrospective 3 / 3 result did not generalise to these three prospectively graded openings. Required interaction content and observed waiting are consistent in this small sample; automatic acceptance of natural-language explanations is not. Combining the two batches into a single favourable rate would hide that distinction, so report them separately.

The next coding step is to revise the disclosure recogniser against the already approved format, with positive paraphrase and negative extra-confirmation/Yes-only/unrelated-link cases, then freeze that new grader before another independent batch. Do not silently extend v3 to fit these outputs or remove required host disclosures. Package extraction accuracy, handwriting and unseen-layout performance require separate evidence. This run changes neither the prompt nor the grader and makes no commit or push.
