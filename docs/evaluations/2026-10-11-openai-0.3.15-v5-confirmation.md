## Change and safeguards

V5 reuses v4's exact source-link validation and visible-text guard. If the existing grammar does not recognise an explanation, v5 parses one quoted waiting rule followed by at most one application clause within the same explanation paragraph. Both parts must match complete bounded clauses. It recognises `require this pause` and `after asking` without inferring arbitrary quoted instructions are safe.

Extra confirmation and Yes-only requirements are still rejected, including inside quotes or the application clause. Unrelated actions, conditions, an additional sentence, multiple links/paragraphs, unrelated sources, absent host evidence and observed pre-reply document work cannot automatically pass. Unrecognised wording remains reviewable. The one-line necessary-disclosure policy is unchanged.

Before execution, deterministic fixtures pass **20 / 20 accepted forms**, **31 / 31 rejected forms**, and **120 / 120 appended-requirement variants**. These are authored recogniser tests, not independent model accuracy. The full suite passes **238 tests**; after a final grammar simplification, all **21 affected tests** pass again before freezing. V5 also reruns inherited v4 source, host, waiting and exact-choice protections. Report tests ensure the v4 dependency is necessary for a prospective v5 report.
