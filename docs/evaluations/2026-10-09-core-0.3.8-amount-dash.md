# Core 0.3.8: default-positive terminal amount dash

The owner requested a positive default for a readable single terminal ASCII dash, without a confirmation question. The processor now applies this default when the option is omitted. Raw/custom strings remain unchanged. Workbook review reasons retain the original converted notation; Run info identifies the default assumption separately from an explicit option.

| Invocation | Effective interpretation | Workbook checks | Expected review flags |
|---|---|---:|---:|
| Option omitted | Positive end mark | 17 / 17 | 3 / 3 |
| Explicit end-mark | Positive end mark | 17 / 17 | 3 / 3 |
| Explicit negative | Negative sign | 17 / 17 | 3 / 3 |
| Explicit unknown | Preserve unresolved text | 17 / 17 | 3 / 3 |
| Total | | 68 / 68 | 12 / 12 |

Twenty-four correct blank checks are excluded. All four runs preserved supplied input/config/reference bytes and processing-script hashes. Default invocation omitted the flag. References are the unchanged, separately authored v1 expectations; the default case uses the positive reference. Previous scores were not rewritten.

All **139 unit/regression tests passed**. They also check that leading negatives, parentheses and CR behavior remain unchanged; malformed/multiple signs are not repaired; quantities and unclear fields cannot be forced numeric. This is deterministic conversion of supplied synthetic JSON, not PDF, model or handwriting accuracy.

The default is a workflow choice, not a universal sign convention. [Oracle](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/erpia/nonstandard_numeric_sign_conventions.html) and [SAP](https://help.sap.com/docs/SAP_Group_Reporting_Data_Collection/64dc0138def94c6696ee1ed4701d53f7/dbca9299d79541e6aef6a390bacce25d.html) document trailing-minus negative formats. These references do not establish a country-by-country handwriting rule. Applicable document/source-format evidence or user instructions can override the default; conflicting evidence can remain flagged text without stopping the task.
