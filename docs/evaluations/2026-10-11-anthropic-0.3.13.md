# Anthropic 0.3.12 and 0.3.13 in Claude Code — 2026-10-11

Follow-up to the [0.3.11 evaluation](2026-10-10-anthropic-0.3.11.md). Two Anthropic-family prompt changes were made, both in `skills/anthropic/SKILL.md` only. Shared core and the OpenAI 0.3.11 package are unchanged.

- **0.3.12** (owner: "1 改"): until the user replies, the only allowed tool call is reading this skill's references. No Glob, Grep, `ls` or shell, and no reading the working folder, custom.md, the company profile or documents. Send the announcement and question, then stop.
- **0.3.13** (owner: "2 一併修"): offer exactly the two reply choices, word for word, "Yes, I have read it." and "No, but I will read it before I upload any confidential data". Do not shorten them or add choices.

Package trees: 0.3.12 `dcd20b36967dfffd661a101fb773c4519b233fd5c48e5ea1003ae34ea353e47f`, 0.3.13 `02fec8a42d5c97d7beccf75907371316492ec904a355178be4f92cd077e7ff8e`. Harness v3.1 is unchanged. Model identity is CLI-reported, not verified. The package remains **experimental**.

Files: [public JSON](2026-10-11-anthropic-0.3.12-0.3.13.json) / [CSV](2026-10-11-anthropic-0.3.12-0.3.13.csv), including the failed batches, and the [aggregate-only Fox JSON](2026-10-11-anthropic-0.3.13-fox-regression.json), which has no values, names or paths.

## Evaluation checker changes (owner decisions)

The Claude opening checker now records `claude-layout-v3.1`; the Codex checker and historical contracts are unchanged. It automatically accepts the following, as long as the choice wording is verbatim and no tool other than the skill's references was used before the reply:

- A short announcement (at most 240 characters) that names the invoice-reader skill. It must ask nothing and claim no work already done.
- Markdown bold around the question or the choices.
- One lead-in line between the question and the choices.
- One closing sentence after the choices.

Anything else still goes to maintainer review.
