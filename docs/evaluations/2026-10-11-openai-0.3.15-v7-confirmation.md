## Source-link change and safeguards

On native Windows, v7 removes exactly one leading slash before an absolute drive prefix, then resolves and compares the target against the installed `SKILL.md` or `references/chat-start.md`. It rewrites only the link target for internal parsing. Source labels, visible prose, quotations, extra-confirmation/Yes-only guards and original evidence remain unchanged. Ordinary relative/absolute links, angle-bracket targets and fragments retain support.

The resolver rejects foreign files/chats/drives, traversal segments, UNC/device paths, drive-relative names, alternate data streams, percent-encoded path spellings, query strings, controls and ambiguous trailing-dot/space segments. The installed root cannot resolve elsewhere; resolved final targets must still match the two permitted source files. Symlink/junction escapes are tested with simulated OS resolution, not privileged creation of actual Windows links. This validates allowed source identity, not complete OS sandbox isolation.
