## Change and protections

V6 retains v5 recognition, then recognises the reverse order: one complete source-linked waiting explanation followed by one quoted waiting rule, separated by a colon, semicolon or sentence boundary. It validates the whole application with the preserved v4 recogniser and the whole quotation with the preserved v5 rule grammar. An internal synthetic connector is only a parsing device; it is never sent to the model or substituted for observed prose. Original link-target case is preserved when checking paths.

Extra confirmation and Yes-only requirements remain blocked across the entire visible paragraph, including inside quotes. Both parts must match; an unrelated action, additional condition, multiple quotes or a third clause cannot pass merely because it also mentions waiting. Relevant installed-source links, matching-session host evidence, exact ordered question/options, one explanation paragraph and observed waiting remain required. Unknown forms are referred.

Before execution, **252 local tests pass**. Authored fixtures accept **28 / 28 valid forms**, reject **43 / 43 invalid forms**, and reject **168 / 168 appended-requirement variants**. Inherited tests recheck older forms, source boundaries, host evidence, waiting and exact choices against v6. A dependency test prevents v6 being labelled prospective without the preserved v5 hash. These are deterministic grading tests, not independent model accuracy.
