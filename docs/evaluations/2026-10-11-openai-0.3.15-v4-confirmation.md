## Grader changes and protection against false passes

V4 separates visible explanation text from its link destination, so an innocuous workspace name containing "confirmation" is not confused with a confirmation request. It verifies the link points to this installed skill's entry or chat-start reference and requires the disclosure rule in the matching session's captured base instructions. Ordered exact question/options, one explanation line and observed waiting remain prerequisites.

The bounded grammar recognises complete waiting clauses, quotation punctuation, source-label variants and synonyms such as `require me to`, `says to`, `instruct me to`, `according to` and `as required by`. It does not pass arbitrary text merely because it mentions waiting. Confirmation/Yes-only guards and whole-clause matching reject extra conditions and unrelated appended actions. Multiple explanations, unrelated links, missing host evidence and pre-reply document work cannot automatically pass. Unknown forms remain reviewable rather than being accepted by omission.

Before the model runs, deterministic cases passed **12 / 12 accepted paraphrases**, **18 / 18 rejected conditions/requirements** and **48 / 48 appended-requirement variants**. The appended cases add another confirmation, a Yes-only restriction, a further permission question or an unrelated upload statement to each accepted paraphrase. These are authored grading fixtures, not independent model outputs or extraction accuracy. All **227 local tests** pass, including source/host checks, frozen-dependency drift and historical-version reporting.

New first-use plans freeze the active v4 hash plus v3/workflow-audit dependency hashes. Continuation rejects drift. Both old and new opening diagnostics are saved; the report tool selects the contract recorded in the plan, and an explicitly selected different grader is labelled retrospective.

## Interpretation

Final verification confirms the frozen package, references, eight execution harness files and three archived test files are unchanged; saved opening grades agree with both reports. Four-batch totals and all exported CSV fields match JSON, all 78 grading-matrix cases agree with expectations, and 86 local links in the updated documents resolve. Package/registry checks and `git diff --check` pass. The 227-test result above is from the final code before freezing; subsequent changes are reports/documentation only.

The frozen v4 grader accepts an output that v3 rejects on the same new sample, while preserving the extra-confirmation and Yes-only guards in the authored regression matrix. It still needs review for unseen explanation structures. This result supports a limited recognition improvement, not universal paraphrase coverage, stable 3 / 3 acceptance, improved document accuracy or full package qualification.

Further work should treat quoted rules and accompanying explanation clauses explicitly, or use separately calibrated semantic review for unknown forms, while retaining deterministic question/order/source/waiting and extra-confirmation checks. Any change needs a new version and a separately frozen test batch; these scores must remain unchanged. No commit or push.
