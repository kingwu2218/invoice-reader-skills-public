## What changed and what the results support

The shared extraction contract now explains how to separate numeric notation, associated printed unit/currency and requested context, and how the existing processor composes the summary. No workbook-processing algorithm or family entry prompt was changed. Both family packages were rebuilt as 0.3.2; there is still one maintained prompt per family.

The new payment configuration asks for cheque amount, currency and Re: context. Its raw observation is `value="8,750/"`, `unit="HKD"`, `context="Lobby hinge inspection"`; the summary is `Lobby hinge inspection: 8,750/ HKD`. The project configuration requests only the Re: text and correctly supplies no unit or additional context. Separate pre-run answers check value, unit, context and summary. This avoids the previous case's missing unit expectation without rewriting its frozen answer or 9 / 10 score. It is a new contract/case, not a retroactive improvement to the old result.

The OCR regression again outputs 105.00 and 6,200 rather than the wrong hidden-layer values 100.00 and 8,200. It preserves the printed arithmetic mismatch for review. Because page images were attached by the evaluator, this run does not demonstrate autonomous PDF routing or tool selection. The corpus also overlaps examples in the skill references, so the matching numbers alone do not isolate visual reading ability; future held-out cases must use independent values/layouts.

## Image evidence

The runner rendered every page from the original public PDFs before model execution and attached each PNG using Codex CLI image arguments in physical page order. It saved source/image hashes, page inventory, archival PNGs and the exact invocation outside the model's working folder. It closed stdin to prevent an inherited pipe from supplementing the recorded prompt. Source and image bytes matched after execution. Re-scoring checked the receipt/invocation/archive hashes and exact attachment list independently of the agent's reading-review ledger.

`supplied_to_cli` establishes the image files supplied to the completed CLI invocation. It does **not** prove server-side delivery, attention to every region or correct interpretation. `attention_verified` remains false. Image assistance is an explicit evaluation mode, not a change to normal skill installation or a model override. Keep its results separate from earlier runs without these attachments.
