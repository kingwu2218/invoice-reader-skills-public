Custom observation Pages are never overwritten. Regression tests reject swapped values and ambiguous IDs. The original pre-fix score remains in the JSON report and local score-before-page-join.json; rescoring used unchanged model artifacts and answers.

Those new references were locked before a fresh conversation and all three stages were executed again. The corrected runs have no structural or field failures. Because the content was reused, this is a regression retest, not an unseen-source holdout.
